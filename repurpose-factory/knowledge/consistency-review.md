# Consistency review

Check every platform piece against the core (and the source when in doubt). You
list fixes; you never rewrite a piece.

## Per piece, check
1. **Claims** — every fact, number, name and quote appears in the core exactly. A quote must be verbatim. Anything else is INVENTED or DRIFTED.
2. **Hedges** — nothing the core marks as uncertain or out of bounds is stated as certain.
3. **Format** — the platform rules hold: word or character counts, structure, front matter, hook placement. Count; do not estimate.
4. **Sameness** — the pieces must not share the same opening, the same examples in the same order, or the same closing line. Flag pairs that read alike.
5. **Machine tells** — stock phrases from the humanizer list.

## The review file
A table: file, check, finding, exact fix (quote the wrong text and give the replacement). Then a verdict line.

CLEAN only when nothing must change; style preferences are not fixes. On a later pass, check that each earlier fix landed and nothing new broke; do not open new rounds of taste.
