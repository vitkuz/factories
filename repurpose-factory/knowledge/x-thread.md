# X thread

- 5–9 posts, each at most 280 characters (count them). Number them `1/`, `2/` …
- Post 1 stands alone: the hook plus the promise of the thread. No "A thread 🧵" filler.
- One point per post, from the core's key points, in an order that builds.
- Use the core's numbers and quotes; never round or embellish them.
- Last post: the takeaway, then the source link.
- No hashtags except at most one in the last post.
- File: the posts separated by blank lines, then `---`, then the character count per post and the core points used.
