# Russian interrogative form (load-bearing)

Applies when the output language is Russian. For another language, keep that language's proper question form and never a statement with a question mark.

A Russian question needs the particle "ли" or a fronted question word. A statement with a question mark is not a question and is a regression even when it reads naturally.

| Bad (statement with "?") | Good (question) |
|---|---|
| В политике есть друзья? | Есть ли в политике друзья? |
| Можно дружить в политике? | Можно ли дружить в политике? |
| В старости противятся новому? | Правда ли, что в старости противятся новому? |

Rules:
1. "ли", "разве", "неужели" are not filler words. Never strip them when shortening.
2. If a source question contains "ли", every shortened version keeps it.
3. When two candidates carry the same thought, one with "ли" and one without, always prefer the "ли" version.
4. Question words ("почему", "как", "где", "кому", "что такое") stand at the front.
